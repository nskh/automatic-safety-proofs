Examples for our paper live in this directory.

To run the examples, run `python pvs-examples/example_X.py` from outside this directory (one level up). You may need to set `PYTHONPATH=.` first. If you're using temp directories, be careful to run from the right place. It will produce a `example_X.pvs` file that you can then check with the PVS prover. To run those in PVS run `proveit --traces example_X.pvs`. Always run with `--traces` so you can see what is going on. After you run `proveit --traces` you can look inside `example_X.log` and see how the proofs went. This is verbose, but you can often find the failed goals by searching for "postpone".

The PVS theory generated by the `.pvs` files will be the same, so if you want to proofcheck multiple at once, you will need to remove the old ones. Do NOT do this inside this `pvs-examples` directory but you can make a `temp/` directory inside here to run and check the example under consideration. There may already be temp directories for each example, so copy the experiments into there. No need to remove stuff just `cp` the example.pvs file into that dir and run `proveit`.
