Examples for our paper live in this directory.

To run the examples, run `python example_X.py` from outside this directory (one level up). It will produce a `example_X.pvs` file that you can then check with the PVS prover. To run those in PVS run `proveit example_X.pvs`.

The PVS theory generated by the `.pvs` files will be the same, so if you want to proofcheck multiple at once, you will need to remove the old ones. Do NOT do this inside this `pvs-examples` directory but you can make a `temp/` directory inside here to run and check the example under consideration.

I want to time these experiments. Phase 1, "generating the proof certificate" is the Python script stuff. Phase 2, "checking the proof certificate" is the PVS stuff. When you time the experiments, store the results in a format that I can later use to make nice tables for the paper.
