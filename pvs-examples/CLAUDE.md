Examples for our paper live in this directory.

To run the examples, run `python pvs-examples/example_X.py` from outside this directory (one level up). You may need to set PYTHONPATH first. It will produce a `example_X.pvs` file that you can then check with the PVS prover. To run those in PVS run `proveit example_X.pvs`.

The PVS theory generated by the `.pvs` files will be the same, so if you want to proofcheck multiple at once, you will need to remove the old ones. Do NOT do this inside this `pvs-examples` directory but you can make a `temp/` directory inside here to run and check the example under consideration. There may already be temp directories for each example, so copy the experiments into there. No need to remove stuff just `cp` the example.pvs file into that dir and run `proveit`.
